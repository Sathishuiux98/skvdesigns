Sathishkumar V — portfolio website (skvdesigns.com)

HOW TO PUBLISH ON VERCEL
Upload everything in this folder, keeping the structure. The img folder holds
282 files: if you upload through GitHub's website, it only takes 100 files at a
time, so upload img in batches. Using the Vercel CLI or dragging the folder into
Vercel avoids that.

vercel.json turns on clean URLs (/los-toolkit) and redirects the old /me-titan
address to /employee-portal.

AFTER IT IS LIVE
1. Google Search Console: add skvdesigns.com (Domain property, DNS record in GoDaddy).
2. Submit https://skvdesigns.com/sitemap.xml
3. Request indexing for the home page and each case study.
4. Check link previews with LinkedIn Post Inspector.
