Sathishkumar V — portfolio website

HOW TO PUBLISH
Upload everything in this folder (keep the structure) to Netlify, Vercel or
Cloudflare Pages. index.html is the home page; 404.html is the not-found page.
The img folder holds 282 files: if you upload through GitHub's website, it only
takes 100 files at a time, so upload img in batches (or use Vercel's own upload).
vercel.json turns on clean URLs on Vercel. Netlify and Cloudflare Pages do this on their own.

AFTER YOU PICK A DOMAIN (send it to Claude and it will regenerate this folder)
- canonical URL on every page, full-URL preview images, sitemap.xml
